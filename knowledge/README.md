# Knowledge Pack

Đây là hub project memory cho GitHub Copilot và các lần chỉnh sửa tiếp theo.

## Các thư mục

- `knowledge/` - project facts, scope, và current decisions
- `skill/` - workflows lặp lại và hướng dẫn theo task
- `rule/` - coding rules và editing rules
- `architect/` - system design và data flow
- `memory/` - durable decisions, known issues, và operational notes

## Cách sử dụng

- Đọc `index.md` trước.
- Giữ tài liệu ngắn gọn, rõ ràng, và dựa trên fact.
- Khi implementation thay đổi, hãy cập nhật file liên quan.
